# Visual Design

Zora's desktop app should feel like the control hub of a practical fairy who got
extra nerdy with computers and information. She is usually studying in her tower,
watching patterns, organizing notes, and helping the creator turn conversations
into useful output.

## Desktop hub theme

Core direction: dark blue and pinky-purple.

Design goals:

- Readable enough for long stream sessions.
- Slightly magical without becoming childish.
- Practical controls first, decorative effects second.
- Clear live status for listening, sleeping, muted, panic, OBS, Warudo, Drive,
  and Make automation.

Suggested palette:

- Deep navy app background.
- Midnight blue panels.
- Pinky-purple primary accent.
- Lavender secondary accent.
- Soft glow around active listening or thinking states.
- Strong red/orange only for panic or errors.

## Zora character visuals

Warudo is already set as the avatar layer. The MVP can use a human avatar while
Zora's behavior and triggers communicate her practical-fairy identity.

Required trigger set:

- Idle/present.
- Hover or subtle float.
- Listening.
- Thinking/studying.
- Speaking.
- Sleeping/resting.
- Awake transition.
- Muted.
- Panic/emergency stop.
- OBS-live sleeping loop.

Later, the visual model can be updated into a more explicitly fairy-like form
without changing the Zora desktop app architecture.
